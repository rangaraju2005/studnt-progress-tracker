# Student Progress Report Tracker

A Python-based project that tracks, analyzes, and reports student academic progress using structured data. This project is implemented in a Jupyter Notebook and is designed for educators or students who want a simple way to monitor performance and generate progress summaries.

## 📌 Project Overview

The **Student Progress Report Tracker** allows users to:

* Store student details and scores
* Calculate averages and overall performance
* Generate clear progress reports
* Easily extend the notebook for additional metrics

This project is beginner-friendly and suitable for learning data handling and basic analysis in Python.
